A one-line warning label for a time machine, written to `/output/entry.txt` by `main.ts`. The label is 112 characters, inside the 120-character limit.

> WARNING: Never meet your past self. Only one of you may return, and he has already reported you for trespassing.

## Run

```sh
node main.ts
```

Reads nothing, needs no network, writes exactly one file: `/output/entry.txt`.
